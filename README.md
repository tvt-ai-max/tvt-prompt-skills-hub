An open-source, interactive catalog curated for modern AI Native workflows, Solopreneurs (OCP), and Agency Teams. Evolved beyond static prompt libraries like `prompts.chat` into an actionable 3-tier capability engine.

---

## ⚡ The 3-Tier Architecture
1. **Prompts (Micro-Prompts):** Lightweight, focused instructions equipped with dynamic variable forms (`{{VARIABLE}}`) and live previews.
2. **Skills (Agent SOPs):** Production-ready procedures formatted in `SKILL.md` with input schemas, step-by-step SOPs, and strict quality audit gates.
3. **Boosts (Meta-Prompts & Slash Commands):** Deep Chain-of-Thought, Tree-of-Thought, and Red-team strategic reasoning for complex system design.

---

## 🚀 Key Features
- **Interactive Variable Form:** Fill in placeholders and copy the final customized prompt in seconds.
- **1-Click Multi-Target Copy:**
  - 📋 Clean Markdown for ChatGPT & Claude
  - ⚡ Cursor Rules snippet (`.cursorrules`)
  - 🤖 Agent Capability file (`SKILL.md` for OpenClaw / Hermes / Claude Code)
- **High-Performance Command Palette (`Cmd+K` / `Ctrl+K`):** Blazing fast fuzzy search across all items, categories, and tags.
- **Zero Database Latency:** GitOps content layer driven directly from markdown and JSON files.
- **Dark Cyber UI:** Designed with an immersive, eye-friendly `#0A0F1E` cyber aesthetic.

## 🛠️ Quickstart for Developers

```bash
# Clone the repository
git clone https://github.com/tvt-ai-max/tvt-prompt-skills-hub.git
cd tvt-prompt-skills-hub

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to explore the hub.
