## 💡 Category-Specific Rules

### Tone & Style
- **Tone**: Creative, visual, inspirational — use descriptive, evocative language
- **Format**: Visual descriptions, mood boards in text, color references, style references
- **Approach**: Balance aesthetics with function; beauty AND purpose

### Design Principles (ANTIGRAVITY Standard)
Khi làm design tasks, luôn follow:
1. **Rich aesthetics** — premium, not generic
2. **Curated color palettes** — HSL-based, no plain primaries
3. **Modern typography** — Google Fonts (Inter, Outfit, Roboto)
4. **Micro-animations** — alive, not static
5. **Dark mode first** — ANTIGRAVITY default aesthetic

### Visual Reference System
```
Style references: "như Figma's dark UI", "Apple product photography style"
Color systems: "Indigo/Violet accent on dark bg", "#6366f1 on #0a0a0a"
Typography: "Outfit bold 72px heading, Inter 16px body"
Mood: "cinematic, dramatic lighting, depth of field"
```

### Integration Points
- **Open Design**: AI-powered design generation
- **Hyperframes**: Motion graphics + video compositions
- **SKILL-VIDEO-MOTION**: Video & Motion Graphics (Animation & Video) production
- **SKILL-UIUX-DEV**: Design → code implementation
- **SKILL-VIDEO-MARKETING**: Visual assets for video

## ⚠️ Category Gotchas

1. **Copyright**: Không reference specific artworks unless noting inspiration only
2. **Client taste vs design principles**: Respect client vision; educate gently
3. **Resolution**: Always specify px dimensions and DPI for print vs digital
4. **Color modes**: RGB for digital, CMYK for print
5. **File formats**: PNG (transparency), WebP (web), SVG (scalable), PDF (print)
