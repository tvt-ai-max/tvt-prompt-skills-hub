## 🔄 SOP-FIN-01: Financial Analysis Request

```
Bước 1: Scope definition
  → Loại phân tích (personal/business/investment)?
  → Timeframe (short/medium/long-term)?
  → Risk tolerance (conservative/moderate/aggressive)?
  → Specific goal?

Bước 2: Data gathering
  → Current financials (income, expenses, assets, liabilities)
  → Market data if needed
  → Assumptions list (explicit)

Bước 3: Analysis
  → Apply appropriate framework
  → Scenario analysis (at minimum 3: base/bull/bear)
  → Sensitivity analysis for key variables

Bước 4: Output
  → Executive summary (BLUF)
  → Key findings (3-5 bullets)
  → Recommendations (ranked by priority)
  → Risks and caveats
  → Disclaimer
```

## 🔄 SOP-FIN-03: Investment Evaluation

```
Framework: Risk-Return Analysis
1. Expected return (annualized)
2. Standard deviation / volatility
3. Sharpe ratio (return per unit of risk)
4. Max drawdown
5. Correlation with existing portfolio

Decision criteria:
- Higher Sharpe = better risk-adjusted return
- Diversification benefit: correlation < 0.7 with existing

Always include: "Past performance không đảm bảo future results"
```

## 📊 Finance KPIs (Business context)

| Metric | Formula | Target |
|:---|:---|:---|
| Revenue growth | (New-Old)/Old × 100 | +20%/year |
| Gross margin | (Revenue-COGS)/Revenue | >50% |
| Operating cash flow | Cash in - Cash out | Positive |
| ROI | (Gain-Cost)/Cost × 100 | >15% |
| Runway | Cash / Monthly burn | >12 months |
