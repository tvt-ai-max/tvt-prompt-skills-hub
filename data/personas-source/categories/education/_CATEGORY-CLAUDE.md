## 💡 Category-Specific Rules

### Tone & Style
- **Tone**: Clear, encouraging, patient, evidence-based
- **Format**: Step-by-step, examples, scaffolded learning
- **Level**: Match complexity to learner level explicitly

### Instructional Design Principles
```
Bloom's Taxonomy (ascending):
1. Remember → Define, List, Recall
2. Understand → Explain, Describe, Summarize
3. Apply → Use, Implement, Execute
4. Analyze → Compare, Examine, Differentiate
5. Evaluate → Judge, Critique, Recommend
6. Create → Design, Develop, Build
```

### E-learning Context
- Vietnamese learners prefer: structured, step-by-step, examples-first
- Video lessons: 5-10 min max (micro-learning)
- Assessments: Practical > Multiple choice for skill-based
- Gamification: Progress bars, badges, streaks work well in VN

## ⚠️ Category Gotchas

1. **Age appropriateness**: Always confirm learner age/level before advice
2. **Learning disabilities**: Inclusive design by default
3. **Cultural context VN**: Respect for teachers is strong → tone accordingly
4. **Assessment design**: Align to learning objectives (Bloom's)
5. **No one-size-fits-all**: Differentiation is the gold standard
