> SOPs cho education design và instructional tasks.

---

## 🔄 SOP-EDU-01: Course/Module Design

```
Bước 1: Learning Objectives (LOs)
  → Viết 3-5 LOs dùng Bloom's verbs
  → "Sau bài học, học viên có thể [verb] [knowledge]"
  → Example: "Học viên có thể phân tích cấu trúc SEO on-page"

Bước 2: Content Outline
  → Module 1: Introduction + Why
  → Module 2-N: Core concepts (logical sequence)
  → Module N+1: Practice + Application
  → Module N+2: Assessment + Summary

Bước 3: Content per Module
  → Video script (5-8 min)
  → Reading material (500-1000w)
  → Practice activity (hands-on)
  → Quiz (5-10 questions)

Bước 4: Assessment Design
  → Align to LOs (each LO tested)
  → Mix: Quiz + Project + Reflection
  → Rubric for project assessment
```

## 🔄 SOP-EDU-02: Lesson Plan Template

```markdown
## Lesson: [Title]

**Duration**: [X minutes]
**Level**: [Beginner/Intermediate/Advanced]
**LOs**: After this lesson, learners can:
1. [Bloom's verb] [skill]
2. [Bloom's verb] [skill]

### Hook (5 min)
[Engaging question or scenario to activate prior knowledge]

### Instruction (15-20 min)
[Core content delivery — explain + demonstrate]

### Guided Practice (10 min)
[Learner attempts with teacher support]

### Independent Practice (10 min)
[Learner applies independently]

### Assessment (5 min)
[Exit ticket, quiz, or reflection]

### Materials
- [Resource 1]
- [Resource 2]
```

## 🔄 SOP-EDU-03: Educational Video Script

```
Format cho micro-learning video (5-8 min):

[0:00-0:30] Hook: Câu hỏi hoặc vấn đề thực tế
[0:30-1:00] Overview: "Hôm nay bạn sẽ học được..."
[1:00-5:00] Core Content: Explain → Example → Demo
[5:00-6:30] Practice: "Hãy thử làm..."
[6:30-7:30] Summary: "Chúng ta vừa học..."
[7:30-8:00] Next: "Bài tiếp theo sẽ..."
```
