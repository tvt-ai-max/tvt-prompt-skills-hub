## 🔄 SOP-FIT-01: Fitness Program Design

```
Bước 1: Client Assessment
  → Goal: [Weight loss / Muscle gain / Endurance / General health]
  → Current fitness level: [Beginner / Intermediate / Advanced]
  → Injuries / limitations: [None / Specific issues]
  → Available time: [X days/week, X min/session]
  → Equipment: [Gym / Home / Bodyweight only]

Bước 2: Program Structure
  → Frequency: [X days/week]
  → Split: [Full body / Upper-Lower / PPL / Other]
  → Progressive overload plan
  → Deload week (every 4-6 weeks)

Bước 3: Session Design
  → Warm-up: 5-10 min
  → Main workout: 30-50 min
  → Cool-down/stretch: 5-10 min

Bước 4: Monitoring
  → Track: Weight lifted, reps, sets
  → Progress photos: Every 4 weeks
  → Measurements: Every 2 weeks
  → Adjust: Every 4-6 weeks
```

## 🔄 SOP-FIT-03: Nutrition Plan Framework

```
1. Calculate TDEE (Total Daily Energy Expenditure)
   → BMR × Activity factor
   → BMR (men): 10×weight + 6.25×height - 5×age + 5
   → BMR (women): 10×weight + 6.25×height - 5×age - 161
   → Activity: Sedentary×1.2, Light×1.375, Moderate×1.55, Active×1.725

2. Set calorie target
   → Weight loss: TDEE - 300-500 kcal
   → Maintenance: TDEE
   → Muscle gain: TDEE + 200-300 kcal

3. Macros
   → Protein: 1.8-2.2g/kg (priority #1)
   → Fat: 25-30% of calories
   → Carbs: Remaining calories

4. Meal timing
   → Pre-workout: Carbs + protein (1-2h before)
   → Post-workout: Protein + carbs (within 30-60 min)
   → Hydration: 35ml/kg minimum
```

## 🔄 SOP-FIT-04: Fitness Content Creation (for blog/social)

```
Fitness content that performs well:
- "X day challenge" → SKILL-UGC-CREATOR
- "How I transformed in X weeks" → Storytelling + before/after
- "5 exercises for [goal]" → Quick tutorial → Hyperframes
- "Debunking fitness myths" → Educational + controversial
- "Day in my life (fitness edition)" → GRWM format

Always include:
  → Proper form cues (safety)
  → Modification for beginners
  → Medical disclaimer
  → Progress encouragement
```

## 📊 Fitness KPIs

| Metric | Measurement | Frequency |
|:---|:---|:---|
| Body weight | Scale, same time | Weekly |
| Body measurements | Tape measure | Bi-weekly |
| Strength progress | Key lifts (kg/reps) | Per session |
| Endurance | Run time/distance | Weekly |
| Energy levels | Self-rating 1-10 | Daily |
| Sleep quality | Hours + rating | Daily |
