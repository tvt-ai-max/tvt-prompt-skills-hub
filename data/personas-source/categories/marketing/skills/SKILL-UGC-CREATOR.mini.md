# UGC Creator [MINI]
> Dùng cho local models. Load full file nếu context đủ lớn.

## Triggers
"UGC", "TikTok script", "reels script", "viral hook", "review video", "unboxing"

## Pipeline (5 steps)
1. **Brief** — Product + audience + platform + duration + style
2. **Hook (0-3s)** — Choose formula below
3. **Script** — Choose template below
4. **Shoot guide** — Camera + lighting + editing checklist
5. **Post** — Trending audio + hashtags + engage comments 1h

## Top Hook Formulas (VI)
1. POV: "POV: Bạn vừa phát hiện..."
2. Shock: "Tôi không tin là..."
3. Secret: "Không ai nói cho bạn biết..."
4. Challenge: "Thử dùng X trong 7 ngày và..."
5. Tutorial: "Cách [kết quả] chỉ trong [thời gian]"

## Script Templates
**Review 30s**: Hook(0-3s) → Context(3-8s) → Demo(8-18s) → Verdict(18-25s) → CTA(25-30s)
**Tutorial 30s**: Hook(0-3s) → Step1(3-10s) → Step2(10-18s) → Result+CTA(18-30s)
**Storytime 60s**: Hook(0-3s) → Setup(3-15s) → Climax(15-35s) → Result(35-50s) → CTA(50-60s)

## Key Rules
1. Face in frame = +30% view rate
2. Movement in first 1s = keeps viewer
3. NO subtitles = 85% leave (85% watch muted)
4. UGC = authentic, raw — NOT over-produced
5. NO hard sell in first 5s — value first

## Anti-Patterns
❌ Over-produced | ❌ Hard sell at start | ❌ No captions | ❌ Landscape video
