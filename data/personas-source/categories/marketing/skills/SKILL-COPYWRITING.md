## Step 2: Research & Framework Selection

### Copywriting Frameworks

#### PAS (Problem-Agitate-Solve)
```
P: [Nêu vấn đề của khách hàng]
A: [Khơi sâu nỗi đau — hậu quả nếu không giải quyết]
S: [Giới thiệu giải pháp — sản phẩm/dịch vụ]
```

#### AIDA (Attention-Interest-Desire-Action)
```
A: [Headline gây chú ý]
I: [Thông tin thú vị, insight mới]
D: [Benefits, social proof, tạo khao khát]
A: [CTA rõ ràng, urgent]
```

#### BAB (Before-After-Bridge)
```
B: [Trước — tình trạng hiện tại của khách]
A: [Sau — cuộc sống sau khi dùng sản phẩm]
B: [Cầu nối — sản phẩm là giải pháp]
```

#### 4Ps (Promise-Picture-Proof-Push)
```
Promise: [Cam kết giá trị]
Picture: [Vẽ bức tranh kết quả]
Proof: [Bằng chứng — testimonial, số liệu]
Push: [Thúc đẩy hành động]
```

## Step 3: Write — Format Templates

### Headlines (10 formulas)

```
1. "Cách [đạt kết quả] trong [thời gian] mà không cần [rào cản]"
2. "[Số] bí quyết để [kết quả] mà [đối tượng] nào cũng áp dụng được"
3. "Tại sao [vấn đề phổ biến] và cách khắc phục trong [thời gian]"
4. "Bạn có đang mắc [sai lầm phổ biến] khi [hoạt động]?"
5. "[Kết quả ấn tượng] — Và đây là cách tôi làm được"
6. "Đừng [hành động sai] cho đến khi bạn đọc bài này"
7. "Cuối cùng! [Giải pháp] cho [vấn đề] mà ai cũng gặp"
8. "[Đối tượng]: Đây là [giải pháp] bạn đang tìm kiếm"
9. "Sự thật về [chủ đề] mà không ai nói cho bạn"
10. "[X] vs [Y]: Cái nào thực sự tốt hơn cho [mục đích]?"
```

### Email Copy Template

```
Subject: [Hook — urgency/curiosity/benefit] (40-60 chars)
Preview: [Bổ sung subject, tạo tò mò] (40-90 chars)

---

[Greeting — personal]

[Hook — 1-2 câu gây chú ý]

[Problem — empathize với vấn đề]

[Solution — giới thiệu giải pháp]

[Benefits — 3 bullet points]
• Benefit 1 (kết quả cụ thể)
• Benefit 2 (tiết kiệm gì)
• Benefit 3 (khác biệt gì)

[Proof — testimonial hoặc số liệu]

[CTA — button hoặc link rõ ràng]
→ [CTA TEXT — action verb + benefit]

[P.S. — urgency hoặc bonus]

---
[Signature]
```

### Landing Page Copy Structure

```
HERO SECTION:
  H1: [Value proposition — 10 words max]
  Subtitle: [Supporting statement — 20 words]
  CTA: [Button text — action verb]
  Social proof: [X+ customers / X★ rating]

PROBLEM SECTION:
  H2: [Empathize with pain point]
  3 pain points with icons

SOLUTION SECTION:
  H2: [Introduce your solution]
  Feature → Benefit mapping (3-5 items)

SOCIAL PROOF SECTION:
  Testimonials (3)
  Logos / Numbers

CTA SECTION:
  H2: [Urgency or summary benefit]
  CTA button
  Risk reversal (guarantee, free trial)

FAQ SECTION:
  5-7 questions
```

### Ad Copy (Facebook/Google)

```
Facebook Ad:
  Primary text: [Hook + value + CTA] (125 chars visible)
  Headline: [Benefit-driven] (40 chars)
  Description: [Supporting info] (30 chars)
  CTA button: [Learn More / Shop Now / Sign Up]

Google Ads:
  Headline 1: [Keyword + benefit] (30 chars)
  Headline 2: [USP or offer] (30 chars)
  Headline 3: [CTA] (30 chars)
  Description 1: [Feature + benefit] (90 chars)
  Description 2: [Social proof + CTA] (90 chars)
```

## Step 4: Optimize

### Copy Checklist

- [ ] Headline gây tò mò hoặc shock?
- [ ] Benefits > Features?
- [ ] CTA rõ ràng, 1 action duy nhất?
- [ ] Social proof included?
- [ ] Urgency/scarcity (nếu phù hợp)?
- [ ] Mobile-friendly (đoạn ngắn, dễ scan)?
- [ ] Power words used? (Free, Proven, Instant, Secret, Exclusive)
- [ ] Tone phù hợp audience?
- [ ] Grammar/spelling checked?

### Power Words (Vietnamese)

```
Urgency: Ngay bây giờ, Có hạn, Cuối cùng, Đừng bỏ lỡ
Trust: Đã chứng minh, Cam kết, An toàn, Miễn phí
Emotion: Bí mật, Kinh ngạc, Tuyệt vời, Độc quyền
Action: Khám phá, Bắt đầu, Nhận ngay, Trải nghiệm
```

## Anti-Patterns

1. ❌ Feature dumping — luôn convert feature → benefit
2. ❌ Weak CTA ("click here") — dùng action + benefit ("Nhận ưu đãi ngay")
3. ❌ Wall of text — short paragraphs, bullet points
4. ❌ Lying/exaggerating — authentic, honest claims
5. ❌ Multiple CTAs — 1 primary action per piece
6. ❌ Generic copy — personalize cho audience cụ thể
