### Viral Loop Blueprints

```
Loop 1: Content Viral
User sees content → Shares → Friend sees → Signs up → Creates content → Share

Loop 2: Invite Viral  
User gets value → Invites friend (incentive) → Friend signs up → Both get reward

Loop 3: Side-effect Viral
User uses product → Product visible to others (badge, watermark) → Others discover

Loop 4: Social Viral
User creates → Posts to social → Friends see → Visit → Sign up
```

## Measurement Framework

### ICE Scoring for Experiment Prioritization

```
I = Impact (1-10): How much will this move the needle?
C = Confidence (1-10): How sure are we it'll work?
E = Ease (1-10): How easy is it to implement?

Score = (I + C + E) / 3

Priority: Score > 7 = Do now | 5-7 = Plan | <5 = Backlog
```

## Anti-Patterns

1. ❌ Growth without product-market fit
2. ❌ Testing too many things at once
3. ❌ Vanity metrics (followers) over actionable metrics (conversion)
4. ❌ Copying tactics without adapting for context
5. ❌ No tracking/measurement setup before experimenting
