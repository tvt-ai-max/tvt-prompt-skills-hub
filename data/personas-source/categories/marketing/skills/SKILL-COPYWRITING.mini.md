# Copywriting [MINI]
> Dùng cho local models. Load full file nếu context đủ lớn.

## Triggers
"viết copy", "headline", "CTA", "ad copy", "email copy", "landing page copy", "tagline"

## Pipeline (4 steps)
1. **Brief** — Product + audience + goal + format + tone + USP
2. **Framework** — Choose PAS / AIDA / BAB / 4Ps
3. **Write** — Apply template below
4. **Optimize** — Checklist: benefit-first | single CTA | social proof | mobile-friendly

## Frameworks
- **PAS**: Problem → Agitate → Solve
- **AIDA**: Attention → Interest → Desire → Action
- **BAB**: Before → After → Bridge
- **4Ps**: Promise → Picture → Proof → Push

## Headline Formulas (VI)
1. "Cách [kết quả] trong [time] mà không cần [rào cản]"
2. "[Số] bí quyết để [kết quả]"
3. "Tại sao [vấn đề] và cách khắc phục"
4. "Bạn có đang mắc [sai lầm phổ biến]?"
5. "Sự thật về [chủ đề] mà không ai nói"

## Power Words (VI)
Urgency: Ngay bây giờ, Có hạn, Đừng bỏ lỡ
Trust: Đã chứng minh, Cam kết, An toàn
Action: Khám phá, Nhận ngay, Trải nghiệm

## Key Rules
1. Benefits > Features (3:1 ratio minimum)
2. One CTA per piece only
3. Short paragraphs for web (3-5 sentences)
4. Social proof always included
5. Test headline before anything else

## Anti-Patterns
❌ Feature dumping | ❌ Weak CTA ("click here") | ❌ Multiple CTAs | ❌ Wall of text
