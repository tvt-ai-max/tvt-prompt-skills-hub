# Social Media [MINI]
> Dùng cho local models. Load full file nếu context đủ lớn.

## Triggers
"tạo post", "social post", "caption", "hashtag", "lịch đăng bài", "social calendar"

## Pipeline (4 steps)
1. **Platform** — Select platform → apply specs + best times
2. **Create** — AIDA formula: Attention → Interest → Desire → Action
3. **Optimize** — Hashtags + image specs + engagement boosters
4. **Schedule** — Platform-specific optimal times

## Best Times (Vietnam)
- Facebook/IG: 11-13h, 19-21h
- TikTok: 12h, 19h, 21h
- LinkedIn: 8-10h (weekdays)

## Hashtag Mix
30% High volume (>1M) | 40% Medium (100K-1M) | 30% Niche (10K-100K)

## Image Specs
- TikTok/Reels/Stories: 1080×1920 (9:16)
- IG Feed: 1080×1080 (1:1)
- Facebook/YouTube: 1200×630 (16:9)
- LinkedIn: 1200×627

## Key Rules
1. Always end post with a question → drives comments
2. Reply to ALL comments within 1h (algorithm boost)
3. Adapt content per platform — never copy-paste same post
4. 80% value / 20% promotion rule
5. Landscape video NEVER on TikTok/Reels

## Anti-Patterns
❌ Same post all platforms | ❌ Over-hashtag on FB/LinkedIn | ❌ Ignore comments
