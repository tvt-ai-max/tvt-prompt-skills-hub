# Video Marketing [MINI]
> Dùng cho local models. Load full file nếu context đủ lớn.

## Triggers
"video strategy", "video campaign", "YouTube strategy", "video SEO", "thumbnail"

## Pipeline (4 steps)
1. **Strategy** — Platform + video type + goal + CTA
2. **Script** — Time | Voice | Visual | Text overlay | Animation table
3. **Produce** — Delegate to Hyperframes (`SKILL-VIDEO-FACTORY`)
4. **Optimize** — Title/desc SEO | Thumbnail | End screen | Analytics

## Platform Specs
- TikTok/Reels/Shorts: 9:16 | 15-60s | Raw + trending audio
- YouTube: 16:9 | 8-15min | In-depth | SEO-optimized
- LinkedIn: 16:9 | 30s-5min | Professional

## YouTube SEO
- Title: keyword + benefit, 60 chars
- Description: 250+ words, keyword in first 2 lines
- Thumbnail: high contrast + face + max 3 words

## Performance Targets
View-through rate >50% | CTR >5% | Avg duration >50% | Likes/views >4%

## Key Rules
1. Hook in first 3 seconds — always
2. Captions on every video (85% watch muted)
3. Never landscape on short-form platforms
4. Thumbnail = 50% of CTR, don't neglect

## Production Delegation
→ Script done → `npx hyperframes render` via Hyperframes pipeline

## Anti-Patterns
❌ No hook | ❌ No captions | ❌ Landscape on TikTok | ❌ Ignoring thumbnails
