# Growth Hacking [MINI]
> Dùng cho local models. Load full file nếu context đủ lớn.

## Triggers
"growth strategy", "tăng trưởng", "growth hacking", "A/B test", "viral loop", "AARRR"

## Pipeline (4 steps)
1. **Analyze** — AARRR: Acquisition | Activation | Retention | Revenue | Referral
2. **Ideate** — Generate 5-10 experiment ideas, score with ICE
3. **Execute** — Run highest-score experiment
4. **Measure** — Track primary metric → Kill/Scale/Iterate

## AARRR Framework
```
A: Acquisition  → Người dùng đến từ đâu?
A: Activation   → Trải nghiệm đầu tiên tốt?
R: Retention    → Có quay lại?
R: Revenue      → Có trả tiền?
R: Referral     → Có giới thiệu không?
```

## ICE Scoring
`Score = (Impact + Confidence + Ease) / 3`  
→ >7: Do now | 5-7: Plan | <5: Backlog

## Top 5 Acquisition Tactics (ANTIGRAVITY)
1. SEO content cluster (free, high impact, slow)
2. Viral referral program (low cost, very high)
3. UGC campaigns (low cost, high)
4. Community building (free, slow)
5. Cross-promotion partnerships (free, medium)

## Key Rules
1. Product-market fit FIRST — no growth hacking on bad product
2. Test ONE variable at a time
3. Actionable metrics only — not vanity (followers ≠ revenue)
4. Always have tracking BEFORE running experiments
5. Kill underperformers after 48-72 hours

## Anti-Patterns
❌ Testing too many things at once | ❌ Vanity metrics | ❌ No measurement setup
