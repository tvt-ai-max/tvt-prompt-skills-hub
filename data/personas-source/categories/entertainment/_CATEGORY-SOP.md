## 🔄 SOP-ENT-01: Video/Film Production Brief

```markdown
## Production Brief: [Project Name]

**Type**: Music Video / Short Film / Event Video / UGC
**Duration**: [X seconds/minutes]
**Platform**: TikTok / YouTube / Instagram / Film festival

### Concept
[2-3 sentence logline]

### Visual Style
- Mood: [e.g., cinematic, raw, playful]
- Color palette: [e.g., warm tones, neon, desaturated]
- References: [3 example videos/films]
- Camera style: [handheld, static, drone]

### Audio
- Music: [Genre / specific track / original]
- Voice-over: [Yes/No, language, tone]
- SFX: [Key sound design moments]

### Production Needs
- Locations: [Interior/exterior, specific places]
- Talent: [Number of people, roles]
- Equipment: [Camera, lighting, audio]
- Timeline: [Pre-prod / Shoot / Post]

### Distribution
- Platforms: [Where will it be published]
- Aspect ratios needed: [9:16, 16:9, 1:1]
```

## 🔄 SOP-ENT-03: Event Promotion

```
T-30 days: Announcement content → SKILL-SOCIAL-MEDIA
T-14 days: Behind-the-scenes → SKILL-UGC-CREATOR
T-7 days: Countdown + sneak peeks → Social calendar
T-1 day: "Tomorrow" reminder → Email + Social
Day-of: Live updates → Real-time social
Post-event: Highlights + recap → Blog + Video
```
