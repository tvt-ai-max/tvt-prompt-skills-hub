## 🔄 SOP-BIZ-01: Weekly Business Review

**Thời gian**: 30-45 phút / tuần (cuối tuần)

```
1. Review metrics (10 min)
   → Traffic, revenue, key KPIs vs targets
   → What moved? What didn't?

2. Project status (10 min)
   → % complete cho mỗi active project
   → Blockers và cần gì để unblock

3. Next week planning (15 min)
   → Top 3 priorities
   → Task assignments
   → Deadlines

4. Update task.md và logs
```

---

## 🔄 SOP-BIZ-02: Decision Making Framework

Khi đối mặt với quyết định quan trọng:

```
1. Define: Quyết định cần đưa ra là gì?
2. Options: List 3-5 lựa chọn (không ít hơn 3)
3. Criteria: Tiêu chí đánh giá (cost, time, risk, impact)
4. Score: Rate mỗi option trên từng tiêu chí (1-5)
5. Decide: Highest score = recommended
6. Document: Ghi lại quyết định và lý do vào MEMORY.md

Template:
| Option | Cost | Time | Risk | Impact | Total |
|:-------|:----:|:----:|:----:|:------:|:-----:|
| A      |  3   |  4   |  4   |   5    |  16   |
```

## 🔄 SOP-BIZ-03: New Project Initiation

```
Bước 1: Charter (1h)
  → Tên, mục tiêu, success criteria
  → Stakeholders (dù là solo)
  → Timeline estimate
  → Resources needed

Bước 2: Break down (1h)
  → WBS: Phases → Tasks → Subtasks
  → Estimate effort (S/M/L)
  → Identify dependencies

Bước 3: Setup tracking
  → Create task.md in project folder
  → Add to weekly review
  → Set milestone checkpoints
```

## 🔄 SOP-BIZ-04: Vendor/Tool Evaluation

```
Criteria để đánh giá tool/vendor:
1. Cost: Free > Freemium > Paid (monthly) > Paid (annual)
2. Integration: API available? Webhook support?
3. Data ownership: Can export? No vendor lock-in?
4. Reliability: Uptime, support response time
5. Learning curve: Can be up in <1h?

Decision rule: Free tier adequate? → Use it. Paid necessary? → Monthly first.
```
