## 🔄 SOP-WRT-01: Blog Post Production (xoamuai.io.vn)

**Thời gian**: 2-4 giờ / bài

```
Bước 1: Research (30 min)
  → Primary keyword (từ SKILL-CONTENT-STRATEGY)
  → SERP analysis: Top 5 competing articles
  → Unique angle: What can we add that they don't have?
  → LSI keywords: 10-15 related terms

Bước 2: Outline (15 min)
  → H1: Primary keyword + benefit hook
  → H2s: Main sections (4-6)
  → H3s: Sub-points under each H2
  → FAQ section (3-5 questions)
  → CTA at the end

Bước 3: Draft (1-2 hours)
  → Write fast, edit later
  → 1500-2500 words target
  → Each section: 200-400 words
  → Include examples, data, screenshots

Bước 4: Edit (30 min)
  → Check facts
  → Fix grammar/spelling
  → Improve headings
  → Add internal links (3-5)

Bước 5: SEO + Publish (15 min)
  → Meta title + description
  → Categories + tags
  → Featured image + alt text
  → Schedule or publish
```

```markdown

**Target URL**: /[slug]
**Word Count**: [X-Y words]
**Tone**: [Casual/Professional/Technical]
**Audience**: [Who will read this?]

**Purpose**: [Why are we writing this?]
**Unique angle**: [What makes this different?]

**Required sections**:
1. [Section name]
2. [Section name]
3. FAQ

**Internal links to include**:
- [Existing post title → URL]

**CTA**: [What action should reader take?]

**Reference articles**:
- [Competitor URL 1]
- [Competitor URL 2]
```

## 🔄 SOP-WRT-03: Editorial Calendar Management

```
Weekly rhythm:
  Mon: Brief this week's articles
  Tue-Thu: Write + edit
  Fri: Publish + social distribution
  Sun: Review performance + plan next week

Monthly:
  1st week: Review last month performance
  2nd week: Content audit (update old posts)
  3rd week: New pillar content
  4th week: Repurpose + link building
```

---

## 🔄 SOP-WRT-04: Content Update SOP (Refresh Old Posts)

```
Tìm candidates: GA4 → Posts with declining traffic
Process:
1. Check current ranking (GSC)
2. Update statistics + dates
3. Add new sections for missing topics
4. Update internal links
5. Improve meta title/description
6. Change publish date → "Updated [date]"
7. Re-submit to GSC for recrawl
```
