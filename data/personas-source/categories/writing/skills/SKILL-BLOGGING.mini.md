# Blogging [MINI]
> Dùng cho local models. Load full file nếu context đủ lớn.

## Triggers
"viết blog", "blog post", "bài viết xoamuai", "WordPress post", "publish article"

## Pipeline (4 steps)
1. **Research** — Primary keyword + SERP top 5 + unique angle + LSI keywords
2. **Write** — Outline first → draft fast → edit later
3. **SEO** — Meta title/desc + internal links (3-5) + images + schema
4. **Publish** — WordPress → categories/tags → featured image → schedule

## Blog Post Structure
```
H1: [Primary Keyword + Benefit] (50-60 chars)
Meta: [155 chars, keyword + CTA]
Intro: Hook + keyword in first 100 words (150-200w)
H2 sections (4-6): 200-300w each
FAQ section: 3-5 long-tail questions
Conclusion + CTA
```

## Publish Checklist
- [ ] 1500+ words
- [ ] Keyword in H1 + first paragraph + 1-2 H2s
- [ ] Internal links ≥3
- [ ] External authority links 1-2
- [ ] Images with alt text
- [ ] Meta title (50-60ch) + description (150-160ch)
- [ ] Categories + tags set
- [ ] Mobile preview OK

## Key Rules
1. Research keyword BEFORE writing outline
2. Check SERP — write what top 5 miss
3. SEO audit with SKILL-SEO-OPTIMIZER before publish
4. Every blog must link to 3+ existing posts (internal links)
5. Update old posts every 6 months (content decay)

## Anti-Patterns
❌ Thin content | ❌ Keyword stuffing | ❌ No internal links | ❌ Publish without SEO review
